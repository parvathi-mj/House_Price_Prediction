# House Price Prediction Web Application

## Overview

This project is a machine learning web application that predicts house prices based on property features such as bedrooms, bathrooms, living area, lot size, location, and other housing characteristics.

The application is built using Python, Scikit-learn, and Streamlit.

## Features

* Predict house prices using a trained Random Forest Regression model
* Interactive web interface built with Streamlit
* User-friendly input controls
* Real-time predictions

## Dataset

The model was trained using the King County House Sales dataset, which contains housing information including:

* Bedrooms
* Bathrooms
* Living area (sqft)
* Lot size (sqft)
* Floors
* Waterfront status
* View quality
* Condition
* Grade
* Year built
* Location coordinates
* Neighbourhood characteristics

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Joblib

## Model

* Algorithm: Random Forest Regressor
* Problem Type: Regression
* Target Variable: House Price
